# thedottie.app

The website for Dottie, a private cycle tracker for iPhone. Plain HTML, CSS and JavaScript, with no build step and no framework. GitHub Pages serves it from this branch.

The site tracks nothing: no analytics, no cookies, no storage, and no third-party scripts, fonts or embeds. A strict Content-Security-Policy on every page forbids any request to another domain.

Every file in this repository is published at thedottie.app, so only the site's own files belong here.

## Files

- `index.html` the home page.
- `privacy/index.html` the privacy policy.
- `support/index.html` support.
- `assets/css/` the styles. `tokens.css` holds the app's four themes.
- `assets/js/` the demo's made-up data, Dottie's notes, the ring, the demo and the page's behaviour.
- `assets/fonts/` Fraunces, Bricolage Grotesque and Newsreader, latin subsets, with their SIL Open Font Licence files.
- `assets/img/` the icon, the logo mark and the link preview picture.
- `CNAME`, `robots.txt`, `sitemap.xml` hosting files.
